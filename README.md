# Groundhopper

A Java application that helps football fans track stadium visits, record matchday experiences, and explore their personal groundhopping history.

## The Problem

Football fans who enjoy visiting different stadiums often have no centralized way to organize their matchday experiences. Information about stadiums, matches, ratings, and personal memories can end up scattered across tickets, photos, notes, and spreadsheets. I built Groundhopper to bring all of this information together in one application while making it easier to track and analyze my groundhopping experiences.

## How It Works

Groundhopper allows users to build a personal database of football stadiums and record matches they attend at each location.

- Add and manage football stadiums with information such as name, city, country, and home club.
- Record matches attended, including date, teams, competition, and final score.
- Rate stadium atmosphere, appearance, and overall experience.
- Add personal notes about each visit.
- View and filter previous stadium visits.
- Generate statistics about stadiums visited, matches attended, and personal ratings.

The application will store information locally using CSV files, allowing users to keep their groundhopping history between sessions.
