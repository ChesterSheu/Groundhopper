# Groundhopper: Eisenhower Matrix

This matrix organizes project tasks based on their importance and urgency. It helps prioritize the features necessary to complete Groundhopper while separating future improvements from the core requirements.

## Do First (Important and Urgent)

These tasks are essential to building a working application and should be completed first.

- [ ] Set up the Java project and GitHub repository.
- [ ] Create the Stadium and Visit classes.
- [ ] Build the main terminal menu.
- [ ] Implement adding, viewing, and searching stadiums.
- [ ] Implement recording match visits.
- [ ] Save and load information using CSV files.

## Schedule (Important but Not Urgent)

These features improve the application but can be developed after the core functionality works.

- [ ] Add filtering and sorting to visit history.
- [ ] Calculate statistics such as stadiums visited and matches attended.
- [ ] Implement stadium rankings based on personal ratings.
- [ ] Add input validation and error handling.
- [ ] Create a stadium wishlist.
- [ ] Develop a groundhopping achievement system.
- [ ] Improve documentation and project presentation.

## Delegate or Keep Simple (Urgent but Less Important)

These tasks should be handled with simple solutions rather than taking time away from the main application.

- [ ] Use a terminal-based interface instead of building a graphical interface.
- [ ] Allow users to enter stadium and match information manually.
- [ ] Use CSV files instead of setting up a database.
- [ ] Keep the initial data structure simple and easy to maintain.

## Eliminate (Neither Important nor Urgent)

These features are outside the scope of the initial project and would add unnecessary complexity.

- Live football scores and match updates.
- User accounts and cloud synchronization.
- Social features and sharing visits with other users.
- Interactive stadium maps.
- Automatic stadium and match data collection through external APIs.
- Photo uploads and image storage.

## Conclusion

The main priority is to build a reliable application that can store stadiums, record match visits, and preserve user data. Additional features such as statistics, rankings, and achievements will be considered once the core application is functional.
